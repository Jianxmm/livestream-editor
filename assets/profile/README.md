# 我的文稿资料

这里放长期使用的专名、参考案例和整理偏好。同一个文件夹可用于多场直播，不需要改动 Skill。

- `01_专用词库.md`：人物、品牌、产品、术语的正确写法和确认依据。
- `02_参考案例与偏好.md`：希望保留的风格、参考稿位置，以及具体值得学习或避免的地方。

可以直接告诉 AI：“帮我建立直播文稿的个人资料。我主要整理……，读者是……，希望保留……。已有材料在……。请先整理能确定的部分，缺失处标为待补充。”

不需要一次填完。没有参考稿也可以开始整理。AI 可以整理已有信息、提出候选写法和风格建议，不能编造案例、经历或把推测写成已确认。

资料保存在工作区，不能放进 Skill 安装目录或上传到公共仓库。整理新场次时会保存当次资料快照；以后改词库不会改变旧稿。每场实际提供的资料和明确要求优先于长期偏好，事实始终以该场回放和已核资料为准。
