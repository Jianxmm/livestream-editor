## 发布阻断检查

- [ ] 无编造事实或不可追溯数字
- [ ] 两位说话人身份锚点均已确认，原稿每个发言块已在独立时间轴中恰好对齐一次
- [ ] 快语速、短插话、A—B—A、抢话和混合发言均已进入说话人冲突清单
- [ ] 所有“已解决”说话人冲突都写明回放音频/画面、独立声纹、真人回听或当事人确认依据，没有只靠上下文关闭
- [ ] 无说话人归属错误
- [ ] 高置信度说话人来源比对无未记录冲突；边界还原与推翻原标签已区分处理
- [ ] 无跨章节之外的连续同人重复署名
- [ ] 无“我我、在在、但但是”等明显ASR残留，口头禅密度不影响阅读
- [ ] 无关键观点静默遗漏
- [ ] 低置信度内容均已标记或删除
- [ ] 人名、数字、日期、产品名均已回听或待核
- [ ] 已确认专名的错写已清零，待确认专名已进入待核清单
- [ ] A 级模块覆盖 100%，A+B 级语义模块覆盖达到 95%或已说明例外
- [ ] 长访谈成稿纯问答保留率不低于 50%，发言块保留率不低于 30%
- [ ] 发布稿保留有效完整编辑底稿至少 90% 的纯问答内容，且逐字重复和同源近义重复均已复核
- [ ] 开场关系、自然进入、有效短问短答和主要追问链均已保留
- [ ] 导语完成“场景关系—主持人感受—经历低点—转折问题—阅读导航”，且无内部流程语言
- [ ] 每条A/B级追问链没有只剩署名和结论；场景、推导、限定及主持人回应均有去向
- [ ] 主持人的判断/回应和嘉宾原词/情绪在全文持续可辨认
- [ ] 任一说话人的字符保留率不低于50%，或已由真人说明有效去重依据
- [ ] 章节体量无低于10%的碎章或高于35%的巨章，例外已有真人说明
- [ ] 每个语义模块都有来源明确的阅读重点；图片建议不冒充已提供素材
- [ ] 发布稿在最后一个高价值回答处收束，没有截图、摆位、美颜/外貌、现场道具、设备或关播确认尾声
- [ ] 最后10—15分钟的低价值转场已复查，最终总结题与嘉宾回答之间没有咖啡、时间感叹或现场征友打断
- [ ] 内容结尾与运营收口已分层，CTA有本场资料和授权且不计入内容保留率
- [ ] 主稿无“运营素材待补”等内部占位；缺素材时已删除整个运营模块
- [ ] 已完成P1精确时间码回听，并抽查脚本从全场五个区间生成的5段随机音频
- [ ] 待核清单 P0 已全部关闭
- [ ] 非普通校订均进入编辑决策台账，暂定项均与待核清单对应
- [ ] 正文没有整体改写过重警报；低来源重合段落均已逐段复核
