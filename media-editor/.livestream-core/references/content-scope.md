# 有效内容与保留率

先按来源盘点内容，再整理底稿；保留率用来发现删薄，不能代替事实与逐链检查。原回放、原转写和完整底稿始终保留，以下处理只影响临时统计，不删除文件中的文字。

## 哪些内容可以排除

A 级核心内容、B 级有效追问、例子、回应、限定与代价都计入。只有覆盖表已标为 C 的设备调试、无信息互动、重复促销、纯重复、无法恢复的 ASR 碎片、无主题内容的关播尾声可提出排除。“不够精彩”“篇幅太长”不属于理由。同一段含有效内容时，先细分覆盖区间，不能整段扣除。

双人长访谈的 50% 字符、30% 发言轮次下限，以及发布稿相对底稿 90% 的护栏不降低；单人 70% 原有效口述、90% 有效底稿的要求不降低。原始全部内容仍供核对。没有有效排除记录时，继续使用原有统计口径，不自动替旧稿追认删除依据。

## 沿用编辑台账，不增加必填文件

确需排除时，在 `_work/编辑决策台账.json` 的可选 `content_scope` 中记录；不需要排除则保留空数组或不填此字段。

```json
{
  "content_scope": {
    "version": 1,
    "source_sha256": "当前 inputs/02_带时间码原稿.md 的原始字节 SHA-256",
    "full_draft_sha256": "当前 _work/完整编辑底稿.md 的原始字节 SHA-256",
    "exclusions": [
      {
        "id": "C001",
        "start": "02:00:00",
        "end": "02:00:00",
        "category": "关播尾声",
        "source_excerpt": "请看镜头，我们截图，截图后关闭直播。",
        "full_draft_excerpt": "请看镜头，我们截图，截图后关闭直播。",
        "basis": "本场主题问答已结束；此处只有截图与关播指令。",
        "status": "待确认"
      }
    ]
  }
}
```

示例不是实际证据。起止时间必须是实际原稿块的起点，区间须完全位于覆盖表 C 级范围，且不与 A/B 重叠。原文片段必须是该区间里可唯一定位的连续文字，不包含发言人时间标题。

底稿仍有该内容时，填写同源且可唯一定位的底稿片段；只允许标点、空白等机械清理差异，不能把前后有效段落夹带进来。改写后无法证明对应关系时，不扣底稿分母，先保留追溯并说明限制，不能用语义猜测或相似度替代证据。底稿本来未收录该片段时可以填空。多项不能重复或嵌套，不能把整场排空。

`待确认` 只允许暂定预检，会产生提醒；发送或发布检查仍阻断。真人实际核验后，将状态改为 `已回听` 或 `已当事人确认`，补真实 `reviewer` 和日历有效的 `review_date`。AI 不代签，不为通过检查编造确认。原稿或底稿变化后须重新核对并更新对应哈希，不能只复制旧确认。

## 如何看结果

正确去掉截图尾声后，阅读稿无需把尾声放回来凑比例；误删有效案例、追问和条件，仍会触发保留率或覆盖检查。比例通过以后，继续从原稿逐链反查正文，再独立通读，保留真人终审。
