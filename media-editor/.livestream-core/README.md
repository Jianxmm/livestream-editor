# 直播文稿整理

**把直播回放和已有的转写稿，整理成读得顺、尽量保留原话的文字稿。**

将直播回放和带时间的转写稿，整理成便于阅读的文字稿。保留原来的意思、例子和问答，调整分段、标点和多余的口头词；听不清或拿不准的地方单独列出，方便回听确认。

适合整理一个人的课程、经验分享，也适合两个人的访谈对话。正常使用不需要自己写代码。

[下载安装包](https://github.com/Jianxmm/livestream-editor/releases/download/v0.4.1/livestream-editor-0.4.1.zip) · [第一次使用，按这里操作](START_HERE.md) · [看看整理前后的区别](examples/整理前后对比.md)

## 先看看它能帮你做什么

| 你现在遇到的情况 | 它会帮你做的事 |
| --- | --- |
| 转写稿里全是“然后、那个、就是说”，很难读 | 清理多余口头词、整理标点和段落，保留原来的表达和意思 |
| 访谈中来回说话，整理后容易看不清是谁说的 | 按回放核对说话的人，保留提问和回答，拿不准的地方单独列出 |
| 稿子很长，担心整理时漏掉内容 | 对照原稿检查，并留下能找到原文位置的记录 |
| 有些人名、数字听不清 | 告诉你是哪一处、在回放的什么位置，请你确认后再定稿 |

[查看一段虚构的整理示例](examples/整理前后对比.md)。示例只展示文字样式，不代表已经验证了真实长直播的整理质量。

## 使用前准备两份材料

1. **直播视频或录音文件**：先下载到电脑里，目前不能只提供一个网页链接。
2. **带时间的转写稿**：就是从声音转出的文字，每段旁边有 `00:15`、`10:30` 这样的播放位置。SRT、VTT 字幕文件也可以直接提供。[格式示例](examples/带时间码原稿.md)

如果只有视频、还没有转写稿，需要先用转写工具把声音转成文字。人物姓名、主题和容易写错的专有名字，也可以一起告诉 AI。

## 第一次怎么用

**只需安装一个 Skill：`livestream-editor`。** 单人分享和双人访谈的规则、模板与工具都包含在同一个安装包里，无需分别安装。

**使用 Codex：** 下载并解压安装包，把解压后的文件夹位置告诉 Codex，然后复制这句话：

> 请帮我安装这个文件夹里的直播文稿整理工具。先阅读 README.md，再按 TECHNICAL.md 检查需要的工具并完成安装。完成后告诉我接下来需要提供什么；有缺项请用普通话说明，不要只给我一串报错。

安装完成后，新建对话，输入 `$livestream-editor` 调用；如果技能列表没有显示，重启客户端后再试。

**使用 WorkBuddy：** 在“技能 → 添加技能 → 上传技能”中选择安装包，再让它按说明检查需要的工具。当前尚未完成 WorkBuddy 客户端的实际导入验收，遇到问题可按下方入口反馈。

安装好以后，把视频和转写稿的位置告诉 AI：

> 帮我整理这场直播。视频或录音在【文件位置】，转写稿在【文件位置】。请尽量保留原话、例子和问答，整理成容易阅读的文字稿；拿不准的内容单独列出来让我确认，原始文件保留。

## 按自己的词库和习惯整理

可以把常出现的姓名、品牌、术语，以及喜欢的参考稿和整理要求，放在工作区的“我的文稿资料”里。直接告诉 AI：

> 帮我建立直播文稿的个人资料。我主要整理【内容】，读者是【读者】，希望【要求】。已有词库或参考稿在【位置】。请帮我完善专用词库、参考案例和整理偏好；不确定的标为待确认，缺失的先留空。

AI 会使用随包提供的模板协助填写，不需要自己改 Skill。没有词库或参考稿也能开始；个人资料保留在自己的电脑里，升级后可继续使用。[完整说明与可复制提示](PERSONALIZE.md)

## 整理完会拿到什么

先打开 **“00_从这里开始.md”**，里面有三份内容的入口：

- **整理好的正文**：你主要阅读和修改的文字稿。
- **需要你确认的地方**：听不清的人名、数字等问题，以及对应的位置。
- **整理说明，选读**：记录做过哪些调整和检查，想追查时再看。

一个人分享的场次，还会有一份整场音频。文件可以在 AI 助手里打开，也可以用自己熟悉的文字编辑器查看；无需另外安装笔记软件。

## 第一次可能还会遇到这些情况

- **提示缺少处理音频的工具**：把提示交给 AI，按 [安装与操作说明](TECHNICAL.md) 处理。首次需要准备 Python 和 FFmpeg；两人访谈还会下载辅助分辨声音的文件，不需要自己研究里面的代码。
- **AI 请你听几段音频**：有些 AI 软件不能直接听声音，或者有地方无法确认，需要你帮忙核对。它不能只凭转写稿就认定是谁说的。
- **你已经修改过稿子**：告诉 AI 哪一份是你确认的版本，后续处理以这份为准，不能用旧稿覆盖。
- **想换新版**：把新版的文件夹位置发给 AI，让它按说明升级；旧版会先备份。

## 使用范围

目前是试用版，支持中文单人分享、两人访谈；三人及以上的讨论暂不支持。工具不替你完成整场录音转文字，也不会自动发公众号或把稿子发送给别人。正式分享前，仍需要你核对正文和待确认的问题。

这套工具不另收使用费；你使用的 AI 软件可能按原有账号规则消耗额度。声音处理工具在本机运行，AI 软件本身怎样处理素材，按你使用的产品和账号设置执行。
