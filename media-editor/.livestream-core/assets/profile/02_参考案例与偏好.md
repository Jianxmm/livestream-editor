# 参考案例与整理偏好

## 整理需求

- 主要整理什么内容：待补充
- 主要读者与使用场景：待补充
- 希望保留的表达和细节：待补充
- 希望减少的表达：待补充
- 标题、导语、分段等偏好：待补充
- 已明确的其他要求：待补充

AI 可根据明确需求补全偏好；自己建议的内容标注“建议，待确认”，不要当成使用者已同意。没有提供的身份、经历、读者反馈和事实不要补写。

## 参考案例

没有案例可以暂留空白，不影响开始使用。有参考稿时由 AI 为每篇补充：

- 名称与文件位置或链接：
- 哪些段落值得参考：
- 具体学习什么：例如主持人的追问、原词保留、导语或章节组织。
- 哪些地方不照搬：
- 状态与依据：已确认／待确认；来源于谁的要求或哪份实际材料。

优先记录位置和少量必要片段，不必复制整篇私人长稿。相对文件路径以这份个人资料所在目录为基准；也可以提供完整文件路径。无法读取的链接标为“未读取”，不能写成已经分析过。案例只帮助学习呈现方法，其中的事实、人名、数字和经历不能移植到其他直播。

本场快照会保存本文件及其中的索引文字，不自动冻结链接或文件位置指向的完整参考稿。重要片段可直接写入这里，标明来源和学习点，随本文件一起保存；旧场次续作发现外部稿件变化时先比较版本，不用新参考覆盖已有正文。

## 使用后的反馈

记录“具体哪段不合适、希望怎样调整、适用于哪些场景”。AI 先区分一次性要求与长期偏好；只有明确适合长期沿用的结论才更新这里，不用每次改稿自动积累新规则。
