# 第一次使用，照着做就好

这套工具帮你把直播的转写稿整理得更好读。你提供素材，AI 处理文字，拿不准的地方再请你确认。

## 1. 下载完整安装包

点击 [这里下载安装包](https://github.com/Jianxmm/livestream-editor/releases/download/v0.4.1/livestream-editor-0.4.1.zip)。下载后的文件名是 `livestream-editor-0.4.1.zip`，不需要注册 GitHub 账号。

Codex 用户先解压，保留整个文件夹。告诉 Codex 这个文件夹放在哪里，然后发送：

> 请帮我安装这个文件夹里的直播文稿整理工具。请阅读 README.md 和 TECHNICAL.md，检查需要的工具并完成安装。遇到缺项，请说明我需要做什么。

安装完成后新建对话，输入 `$livestream-editor` 调用；列表里没有显示时，重启客户端后再试。

WorkBuddy 用户在“技能 → 添加技能 → 上传技能”中选择 ZIP 文件，再让它检查需要的工具。当前尚未完成该客户端的实际导入验收；如果导入失败，可在 [项目反馈页](https://github.com/Jianxmm/livestream-editor/issues/new?template=usage-help.md) 说明提示内容。

安装包里只有一个 `livestream-editor` Skill，已包含单人分享和双人访谈两种处理方式。需要保留完整文件夹，不能只复制里面的 `SKILL.md`。

## 2. 准备素材

把视频或录音下载到电脑里，再准备同一场直播的转写稿。转写稿需要带播放时间，例如：

```text
发言人1   00:15
今天先分享一下我整理阅读笔记的经历。
```

这里只有一段格式示例，不是让你把整场内容手工打出来。如果还没有转写稿，先从原来的录音或转写工具导出。如果拿到的是 `.srt` 或 `.vtt` 字幕文件，直接提供即可，AI 会用工具保留原件并生成整理副本，不用手工改成上面的格式。字幕必须与回放时间一致；滚动重叠等暂不支持的导出会指出具体位置，不会悄悄丢字。其他格式先交给 AI 检查，保留原文件。

## 3. 让 AI 开始整理

> 帮我整理这场直播。视频或录音在【文件位置】，转写稿在【文件位置】。请尽量保留原话、例子和问答，整理成容易阅读的文字稿；拿不准的内容单独列出来让我确认，原始文件保留。

整理后，先打开“00_从这里开始.md”阅读正文，再处理需要确认的地方。AI 如果请你核对姓名或听几段音频，按提示确认即可；正式发送前自己再看一遍。

首次需要的音频工具可由 AI 协助准备，具体操作在 [安装与操作说明](TECHNICAL.md)。你不需要先看懂这些技术说明才开始使用。

## 想按自己的习惯整理

告诉 AI：“帮我建立直播文稿的个人资料。我主要整理……，读者是……，希望……。请帮我完善词库、参考案例和偏好，不确定的先标出来。”

AI 会把这些内容放进工作区的“我的文稿资料”，以后整理时可以继续使用，不需要另外安装 Skill。没有参考稿也不影响开始。[具体操作](PERSONALIZE.md)

想记录哪里顺手、哪里需要改进，可用 [这份简短试用记录](TRYOUT.md)，正常使用不必先填写。
