# 整理前后，有什么区别

下面是一段为演示编写的虚构对话，只展示整理后的文字样式。它没有对应的真人回放，不是完整场次的验收结果。

## 原来的转写稿

```text
发言人1   00:00
你刚才说记笔记这个事你改过好几次，那后来，后来怎么定下来的？

发言人2   00:06
对，我以前就是，那个，笔记放在三个软件里嘛，每次要分享的时候就找不到。后来我先固定一个地方，然后每篇都写上日期和主题。这一步没有让我读得更快，但下次要用的时候，就能找到了。
```

## 整理后的正文

**提问者：** 你刚才说，记笔记这件事改过好几次。后来怎么定下来的？

**分享者：** 对，我以前笔记放在三个软件里，每次要分享的时候就找不到。

后来我先固定一个地方，每篇都写上日期和主题。这一步没有让我读得更快，但下次要用的时候，就能找到了。

## 它做了哪些调整

去掉了重复和没有实际内容的口头词，补上标点、分开段落；保留原来的经历、转折、例子和提问。

实际任务中，说话人的姓名和听不清的内容要对照回放确认。不会仅凭文字标签认人，也不会为了把句子写顺而补造事实。
