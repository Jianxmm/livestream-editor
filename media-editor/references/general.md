# 通用音视频与文字整理

## 输出选择

默认交付完整整理稿和待核清单；用户若只要求摘要、原始逐字稿、下载或其他体裁，直接按要求交付。已有文本并没有配套原声也可工作，在来源说明中写明无法回听。不要因为短素材无法形成固定章节就拼凑内容。

原始逐字稿保留来源文字、语言和顺序，仅另存排版副本；机器转写如实标识为自动转写，不称作人工逐字核实。摘要可以压缩，但不得遗漏改变结论的限制条件；标明是摘要。用户要求时间标记时仅使用原字幕、分段或真实回放中的有效时间，分段补转须加回偏移；没有可靠时间不推算。

## 组织和核查

1. 确认实际来源、覆盖范围、语言、输出目的、材料质量和说话人线索；没有实际核验就不确定人物身份。对长素材先通读全场，记录原段落或时间范围、话题、案例和观点归属。
2. 沿语义边界处理，保留例子、数字及单位、论证过程、前提、反例、立场及重要原话。去掉纯口头噪音时不删承载限定或转折的词；真实有意义的重复要保留。多人材料中不跨人拼接观点，不将提问当作回答者的事实陈述。
3. 用自然的主题与段落组织全文。依据用户要求决定是否保留对话形式；没有明确要求时，让内容决定结构。不要从简介、提纲或摘要补造原文细节，也不强行加入总结、建议或标题数量。
4. 对专名、数字、听不清的原词和矛盾信息，结合上下文、已确认词库和可用原声检查；只有真实证据足够时才修改。其他情况保守表达并写入待核清单，注明位置、原文、疑点及依据状态。使用本地转写时同时检查切点及识别时间空白，未实际回听的候选列入待核清单，并链接已生成的原声片段或标明原媒体时间；空白不一定代表缺稿。有原声但宿主不能听时，可按需提取片段供真人核对；机器补转是候选，不是听清。
5. 从源材料反查正文，核对前、中、后、关键案例、争议、末尾及分块衔接；说明缺段、只取得字幕、没有原声或只能生成部分稿等限制。单独核查错词、数字、人物归属及文章可读性。未经真人核查不声称人工终审或可直接发布。

待核清单为空时也说明“本轮未发现可列出的疑点；不代表已核实所有事实”；保留资料依据。不自动修改原文，也不覆盖之前经真人确认的成稿。
