# 文稿整理

**0.1.0-beta.1 · 试用版**

[下载安装包](https://github.com/Jianxmm/livestream-editor/releases/download/media-editor-v0.1.0-beta.1/media-editor-0.1.0-beta.1.zip) · [验证情况](VALIDATION.md) · [工具与模型许可](THIRD_PARTY.md)

把直播回放、视频、播客、字幕和已有文稿，整理成忠于原意、方便阅读的文字。既能处理普通内容，也保留直播整理中对原话、问答和待核问题的要求。

你可以只给一份文字，也可以给音视频文件，或提供指向单条内容的链接。是否能取得网页内容、生成转写和核对原声，取决于当前 AI 助手及本机可用的工具；遇到缺项时会说明，不把简介当作逐字稿。

## 它能帮你做什么

| 你提供的内容 | 可以怎么处理 |
| --- | --- |
| 已有转写稿、字幕或文字 | 保留事实、案例和主要观点，调整分段、错字和重复，整理成易读的稿件 |
| 视频或音频 | 先利用可用字幕或转写工具取得文字，再根据需求整理 |
| 视频或播客单集链接 | 尝试读取该条内容、字幕或音频；平台权限和工具会影响是否成功 |
| 直播回放和转写稿 | 按现有直播标准保留原话、分享顺序或双人问答，并列出需要核对的地方 |

它是给支持 Skill 的 AI 助手使用的工作方法与工具，不是单独的 AI 模型，也不自带模型权重或账号。AI 助手仍需能读取文件、执行必要工具和生成文稿。

## 先安装，再告诉 AI 你的需求

下载发布包并解压，把文件夹位置告诉你的 AI 助手，例如：

> 请读取这个文件夹里的文稿整理 Skill，检查当前环境并帮我安装。保留我已有的同名技能，不要覆盖。

也可在解压后的 `media-editor` 目录中运行 `python3 install.py`。安装器校验包内文件，默认安装到 `~/.agents/skills/media-editor`；已有同名目录时停止，不覆盖。若你的客户端使用其他技能目录，请让助手先查明实际位置，再用 `--target` 指定路径。安装后新建对话，使用 `$media-editor`；未显示时重启客户端。

WorkBuddy 的导入和真实素材处理尚未完成实机验收，请以实际客户端的安装方式为准。

## 常见用法和输出选择

不用事先选择技术流程，直接告诉助手你有什么、希望得到什么：

**普通文字、视频或播客**

> 请把这份文稿整理成完整的阅读稿，保留案例、数字和讲者原意，拿不准的地方单独列出：［文件路径］

> 请整理这个播客，保留重要案例和推理过程：［单集链接］

未指定其他体裁时，默认给整理稿和待核问题清单，都是 Markdown 文件。只有文字时能照常整理，但无法通过原声确认转写错误。

**按直播标准整理**

> 请按直播标准整理这场直播，尽量保留真实问答和原话；输出待发布稿和待核清单。回放和转写稿在：［文件路径］

明确要求直播标准时，两份主要交付为**待发布文稿**和**待核对清单**，均为 Markdown。还会按直播核心生成必要的编辑记录和质检材料供追查。待发布稿仍需核对疑点和人工终审，文件名不能代替终审结果。当前完整直播标准适用于单人分享及双人访谈；三人及以上不能按该标准宣称已验收。

**其他形式**

> 只要这段录音的原始逐字稿，保留原语言和说话顺序。

> 只给我这场直播的简短摘要，保留关键限制和重要条件。

> 请把这段内容整理成带真实时间标记的文字稿，方便我回听。

明确只要摘要、逐字稿或下载时，按该要求处理；如果同时要求按直播标准，仍须交付直播待发布稿和待核清单，其他形式作为补充。没有可靠时间信息时不会凭文字长度推算时间。

## 关于原声与转写

已有可靠转写时优先使用，不必重复转写整场。没有文字时，需要本机或助手提供转写能力；有声音也不代表助手一定能听懂。人名、数字、说话人和听不清的表达，能实际核对时按证据处理，不能确认的保留在待核清单。机器转写和上下文推测都不是已经听清的证明。

处理媒体通常需要 FFmpeg；网页获取可使用 yt-dlp。本 Skill 附带一个本地转写入口，可使用已有的 `whisper-cli` 与模型；模型和其他依赖不包含在安装包里。也可以使用助手已提供的其他转写能力。AI 助手可按具体任务检查并说明缺项。

长录音分段转写后，切分位置附近可能漏字或出现错词。本地入口会留下切点及较长未识别时间的核对线索和短音频；空白也可能只是音乐或静音，未回听的候选要列入待核清单。自动转写不能当成已确认的原话。具体工具与使用说明见 [素材获取与转写](references/acquisition.md)。

首次获取模型可能占用磁盘与时间；云转写或云模型可能有费用，素材是否发送到云端取决于使用的服务及用户授权。Skill 自身不提供云额度，也不自动发布或向他人发送内容。

## 维护与分发

开发树中的 `.livestream-core` 指向项目唯一的直播核心；运行 `python3 media-editor/build_package.py --output <新路径.zip>` 时，分发包按直播核心白名单展开为普通文件，接收者无需开发项目或符号链接。隐藏目录用于避免 Codex 将内部核心重复识别为独立 Skill；其他客户端对隐藏目录的支持尚需实测。包内包含直播核心自己的 MIT 许可，不包含私人词库、真实案例、账号、媒体或模型。

文稿整理独立实现，方法参考[音视频转录与长文整理](https://scys.com/skillhub/skills/skl_media-transcriber?from=copy_link&v=1.1.0)，不包含该 Skill 的源码或正文。[已验证的情况与仍需验证的项目](VALIDATION.md)分开记录；当前未声明所有平台、各类设备或 WorkBuddy 均已验收。反馈问题时请提供设备、AI 客户端、输入类型和错误信息，不要上传私人素材或密钥。

依赖工具和模型的许可见 [外部工具与许可](THIRD_PARTY.md)。
